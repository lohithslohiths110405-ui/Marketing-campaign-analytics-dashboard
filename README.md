# Marketing Campaign Analytics Dashboard

## Project Overview

The Marketing Campaign Analytics Dashboard is an interactive Business Intelligence project developed using Power BI. It helps analyze digital marketing campaign performance by tracking impressions, clicks, conversion rates, engagement, and Return on Investment (ROI).

The dashboard provides insights into marketing channels, campaign types, companies, and locations to support better marketing decisions.

## Project Objectives

- Analyze overall marketing campaign performance.
- Monitor impressions and clicks across campaigns.
- Evaluate conversion rates and marketing ROI.
- Compare campaign performance across different channels.
- Identify engagement trends and marketing effectiveness.
- Support data-driven marketing decisions.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## Dashboard Features

### Key Performance Indicators (KPIs)

- Total Campaigns
- Total Impressions
- Total Clicks
- Average Conversion Rate
- Average ROI
- Average Engagement

### Data Visualizations

- ROI Trend Over Time
- ROI by Location
- Conversion Rate by Campaign Type
- Campaign Reach vs Click Performance
- ROI by Marketing Channel
- Interactive Campaign Filters

## Key Performance Insights

- Approximately 200K campaigns are included in the analysis.
- Total impressions are approximately 1 billion.
- Total clicks are approximately 110 million.
- Average conversion rate is 8.01%.
- Average ROI is 5.00.
- Average engagement score is 5.49.
- ROI remains relatively stable across the displayed locations and marketing channels.
- Similar impressions do not always generate proportionally similar clicks.

## Interactive Filters

The dashboard provides filters for:

- Date
- Campaign Type
- Channel Used
- Company
- Location

These filters allow users to explore campaign performance based on different conditions.
